Polkadot Bootcamp – BAD Ethiopia @ AASTU
Repository for exercises and projects from the Polkadot Bootcamp, hosted by BAD Ethiopia at AASTU, including Solidity smart contracts and Web3 experiments.
⚡ Tasks Included
Task 1 – Crowdfunding Contract
Store campaign name, description, funding goal, total funds raised, and creator address
Additional fields: campaign deadline, minimum contribution, is campaign active
Helper functions: remaining funding needed, days until deadline, check if accepting donations
Individual getter functions for all fields
Task 2 – Data Type Experiment
Demonstrates 5+ Solidity data types: uint256, string, bool, address, bytes32
Functions perform operations on each type
Shows difference between state and local variables
🌐 Deployment
Network: Paseo Asset Hub
IDE: Remix Ethereum IDE
Wallet: MetaMask
